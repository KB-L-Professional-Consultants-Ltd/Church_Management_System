# Auth API Bruno Collection

Run this collection from the collection root with Bruno CLI:

```bash
cd bruno/auth-api
bru run --env local
```

The collection targets `http://localhost:3000/api/v1`. You need a valid `DATABASE_URL` and the API server running locally before the auth requests will succeed.

See also the developer-facing authentication guide for endpoint details and frontend integration examples:

- [docs/authentication.md](../../docs/authentication.md)
